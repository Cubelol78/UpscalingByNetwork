# UpscalingByNetwork - Système d'Upscaling Distribué

[![Version](https://img.shields.io/badge/version-1.0.0-blue.svg)](https://github.com/votre-repo/UpscalingByNetwork)
[![Platform](https://img.shields.io/badge/platform-Windows%20%7C%20Linux-lightgrey.svg)](https://github.com/votre-repo/UpscalingByNetwork)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)

## 🎯 Description

UpscalingByNetwork est un système distribué permettant de partager la puissance de calcul entre plusieurs machines pour effectuer de l'upscaling vidéo en utilisant Real-ESRGAN. Le système divise les vidéos en lots d'images qui sont distribués aux clients connectés, puis reassemble le résultat final.

## ✨ Fonctionnalités

### 🖥️ Serveur
- **Interface graphique intuitive** avec monitoring en temps réel
- **Distribution intelligente** des lots avec gestion des doublons
- **Sécurité WAN** avec chiffrement AES-256
- **Monitoring avancé** des clients connectés
- **Assemblage automatique** des vidéos finales
- **Support audio** complet avec synchronisation

### 💻 Client
- **Versions Windows et Linux** autonomes
- **Interface graphique moderne** avec statistiques
- **Traitement automatique** des lots reçus
- **Surveillance système** intégrée
- **Reconnexion automatique** en cas de déconnexion

### 🔧 Technique
- **Réseau WAN** sécurisé avec identification par adresse MAC
- **Real-ESRGAN** intégré pour l'upscaling de qualité
- **FFmpeg** pour le traitement vidéo
- **Compression optimisée** pour les transferts réseau
- **Gestion d'erreurs** robuste avec retry automatique

## 🚀 Installation

### Serveur (Windows)

1. **Téléchargez** le package serveur depuis [releases](https://github.com/votre-repo/UpscalingByNetwork/releases)
2. **Extrayez** l'archive dans un dossier
3. **Lancez** `Start_Server.bat`

### Client Windows

1. **Téléchargez** le package client Windows
2. **Extrayez** l'archive dans un dossier
3. **Lancez** `Start_Client.bat`

### Client Linux

1. **Téléchargez** le package client Linux
2. **Extrayez** : `tar -xzf UpscalingByNetwork_Linux.tar.gz`
3. **Installez** les dépendances : `sudo apt install python3-pyqt5`
4. **Lancez** : `./start_client.sh`

## 📋 Prérequis

### Serveur
- Windows 10/11 64-bit
- 8 GB RAM minimum (16 GB recommandé)
- 50 GB d'espace libre minimum
- GPU compatible Vulkan (recommandé)

### Client Windows
- Windows 10/11 64-bit
- 4 GB RAM minimum
- GPU compatible Vulkan (obligatoire pour Real-ESRGAN)

### Client Linux
- Ubuntu 20.04+ / Debian 11+ / Fedora 35+ ou équivalent
- Python 3.8+
- PyQt5
- GPU compatible Vulkan

## 🛠️ Configuration

### Configuration réseau

Le serveur utilise par défaut le port **8888**. Assurez-vous que :
- Le port est ouvert dans le pare-feu
- Les clients peuvent accéder au serveur via ce port
- Pour un usage WAN, configurez la redirection de port sur votre routeur

### Paramètres d'upscaling

Dans l'interface serveur, vous pouvez configurer :
- **Modèle Real-ESRGAN** : `realesr-animevideov3` (recommandé pour anime/cartoon)
- **Facteur d'échelle** : 2x, 4x ou 8x
- **Taille des lots** : 50 images par défaut
- **Qualité vidéo** : CRF 15-30

## 📖 Utilisation

### Démarrage du serveur

1. **Lancez** l'interface serveur
2. **Configurez** l'adresse IP (0.0.0.0 pour toutes les interfaces)
3. **Cliquez** sur "Démarrer le serveur"
4. **Vérifiez** que le statut indique "Démarré"

### Connexion des clients

1. **Lancez** l'interface client
2. **Configurez** l'adresse du serveur dans l'onglet "Connexion"
3. **Cliquez** sur "Se connecter"
4. **Vérifiez** le statut de connexion

### Traitement d'une vidéo

1. Dans l'interface serveur, onglet **"Gestion des Jobs"**
2. **Sélectionnez** une vidéo dans "Nouveau Job"
3. **Configurez** les paramètres d'upscaling
4. **Cliquez** sur "Créer le Job"
5. **Surveillez** la progression dans "Jobs Actifs"

### Surveillance

L'onglet **"Surveillance"** du serveur affiche :
- Clients connectés avec statut en temps réel
- Progression des lots par client
- Statistiques de performance
- Alertes et notifications

## 🔒 Sécurité

### Chiffrement

- **AES-256-CBC** pour les données transférées
- **Clés de session** uniques par connexion
- **HMAC-SHA256** pour l'intégrité des données
- **Handshake RSA** pour l'échange de clés

### Identification

- **Adresse MAC** pour identifier les clients
- **Tokens de session** avec expiration
- **Authentification** mutuelle serveur/client

### Réseau

- **Validation** des messages réseau
- **Protection** contre les attaques de replay
- **Isolation** des lots par client

# Guide d'Installation - UpscalingByNetwork

## 🚀 Installation Rapide

### Option 1 : Téléchargement des Releases (Recommandé)

1. **Rendez-vous** sur la [page des releases](https://github.com/votre-repo/UpscalingByNetwork/releases)
2. **Téléchargez** les packages correspondant à votre plateforme :
   - `UpscalingByNetwork_Windows.zip` pour Windows (serveur + client)
   - `UpscalingByNetwork_Linux.tar.gz` pour Linux (client uniquement)

### Option 2 : Compilation depuis les Sources

Voir la section [Compilation Avancée](#compilation-avancée) ci-dessous.

## 🖥️ Installation Serveur (Windows)

### Prérequis
- Windows 10 64-bit ou supérieur
- 8 GB RAM minimum (16 GB recommandé)
- 50 GB d'espace disque libre minimum
- GPU compatible Vulkan (optionnel mais recommandé)

### Installation

1. **Téléchargez** `UpscalingByNetwork_Windows.zip`
2. **Extrayez** dans un dossier (ex: `C:\UpscalingByNetwork`)
3. **Naviguez** dans le dossier extrait
4. **Double-cliquez** sur `Start_Server.bat`

L'interface graphique du serveur s'ouvrira automatiquement.

### Configuration initiale

1. Dans l'onglet **"Configuration"** :
   - Configurez l'adresse IP (0.0.0.0 pour écouter sur toutes les interfaces)
   - Vérifiez le port (8888 par défaut)
   - Ajustez la taille des lots selon votre réseau

2. **Cliquez** sur "Démarrer le serveur"

3. **Vérifiez** que le statut indique "Démarré" en vert

## 💻 Installation Client Windows

### Prérequis
- Windows 10 64-bit ou supérieur
- 4 GB RAM minimum
- GPU compatible Vulkan (obligatoire)
- Accès réseau au serveur

### Installation

1. **Utilisez** le même package `UpscalingByNetwork_Windows.zip`
2. **Extrayez** sur la machine cliente
3. **Double-cliquez** sur `Start_Client.bat`

### Configuration initiale

1. Dans l'onglet **"Connexion"** :
   - Saisissez l'adresse IP du serveur
   - Vérifiez le port (8888 par défaut)
   - **Cliquez** sur "Tester la connexion"

2. **Cliquez** sur "Se connecter"

3. **Vérifiez** que le statut indique "Connecté" en vert

## 🐧 Installation Client Linux

### Prérequis système

**Ubuntu/Debian :**
```bash
sudo apt update
sudo apt install python3 python3-pip python3-pyqt5 python3-venv
```

**Fedora :**
```bash
sudo dnf install python3 python3-pip python3-qt5 python3-virtualenv
```

**Arch Linux :**
```bash
sudo pacman -S python python-pip python-pyqt5 python-virtualenv
```

### Installation

1. **Téléchargez** `UpscalingByNetwork_Linux.tar.gz`

2. **Extrayez** :
```bash
tar -xzf UpscalingByNetwork_Linux.tar.gz
cd UpscalingByNetwork_Linux
```

3. **Installez** les dépendances Python :
```bash
pip3 install --user websockets cryptography psutil qasync
```

4. **Rendez exécutable** et lancez :
```bash
chmod +x start_client.sh
./start_client.sh
```

### Dépannage Linux

**Si PyQt5 n'est pas trouvé :**
```bash
# Ubuntu/Debian
sudo apt install python3-pyqt5-dev python3-pyqt5.qtwidgets

# Fedora
sudo dnf install python3-qt5-devel

# Arch
sudo pacman -S python-pyqt5
```

**Si Real-ESRGAN ne fonctionne pas :**
```bash
# Vérifiez les pilotes Vulkan
vulkaninfo

# Installez les pilotes Vulkan si nécessaire
# NVIDIA
sudo apt install nvidia-vulkan-driver

# AMD
sudo apt install mesa-vulkan-drivers

# Intel
sudo apt install intel-media-va-driver-non-free
```

2. **Cliquez** sur "Autoriser une application"
3. **Ajoutez** `UpscalingByNetwork_Server.exe`

1. **Connectez-vous** à l'interface d'administration
2. **Configurez** la redirection de port :
   - Port externe : 8888
   - Port interne : 8888
   - IP locale : IP du serveur
   - Protocole : TCP

```bash
# Test depuis un client
telnet <IP_SERVEUR> 8888

# Ou avec netcat
nc -zv <IP_SERVEUR> 8888
```

## 🚨 Dépannage

### Problèmes courants

**"Dépendances manquantes"**

- Contrôlez les paramètres de pare-feu
- Testez la connectivité réseau

**"GPU non supporté"**
- Vérifiez la compatibilité Vulkan : `vulkaninfo`
- Mettez à jour les pilotes graphiques
- Utilisez le traitement CPU (plus lent)

1. **Consultez** les logs :
   - Serveur : `logs/server.log`
   - Client : `client_work/logs/client.log`
